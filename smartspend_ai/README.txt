SMARTSPEND AI

A Flask + SQLite personal finance dashboard prototype with transaction management, monthly budget, charts, spending estimate, unusual-spending alerts, and rule-based savings recommendations.

LOCAL RUN (Windows / VS Code)
1. Open this folder in VS Code.
2. Run: py -m venv .venv
3. Run: .\.venv\Scripts\Activate.ps1
4. Run: python -m pip install -r requirements.txt
5. Run: python app.py
6. Visit: http://127.0.0.1:5000

Deployment instructions: see DEPLOYMENT.md.
Forecast is a daily-average baseline, not a trained ML model.
